# ScanPathViewer 扫描路径查看器 · 使用手册 V1.1

（团队试用版 · 2026-08 · 写给铸造/SLS工程师，不需要计算机基础）

## 一、这是干什么的

打印之前，把切片软件输出的扫描路径（G代码）一层一层"看"一遍：
**红线=激光扫描线，蓝虚线=空跳线**。缺层、漏扫、越界，一眼看出来，别等砂子和激光白费。

## 二、第一次使用（只做一次，约10分钟）

**第1步 装Python**（电脑上已有的跳过）
- 浏览器打开 python.org → 点黄色"Download Python 3.x"→ 下载后双击安装
- ⚠ 安装第一屏**务必勾选底部"Add Python to PATH"**，再点Install Now

**第2步 下载软件**
- 打开 https://gitee.com/yunlongcasting/scan-path-viewer
- 点右侧橙色"克隆/下载"→"下载ZIP"→ 解压到任意文件夹（如桌面）
- 👍 顺手点一下页面右上角的 **Star（星标）**，支持一下咱自己人的开源项目

**第3步 装依赖**
- 进入解压出的文件夹，**双击 `一键安装.bat`**，等它跑完显示"安装完成"

## 三、日常使用（就两个动作）

1. **双击 `ScanPathViewer演示.bat`** → 软件打开并自带30层演示数据（第一次先用它熟悉操作）
2. 看自己的数据：**把装NC文件的文件夹直接拖进软件窗口**，完事

## 四、界面按钮说明

| 按钮/操作 | 作用 |
|---|---|
| 打开目录 / 打开文件 | 选数据文件夹（多层）或单个.nc文件 |
| 层号框 + ◀ ▶ | 跳层 / 上一层下一层（键盘←→也行） |
| ▶ 播放 | 自动逐层放动画（空格键也行），再按停止 |
| 扫描线G01 / 跳转线G00 | 两种线分别开关显示 |
| 适应 | 视图回到整幅（键盘F） |
| 📏 测量 | 点开后在图上点两个点→显示毫米距离；再点按钮退出 |
| 💾 截图 | 当前画面保存为PNG图片（发群里讨论用） |
| EN / 中文 | 界面语言切换 |
| 鼠标滚轮 | 对着哪儿滚就往哪儿放大缩小 |
| 按住鼠标**中键**拖 | 平移画面 |
| 窗口底部状态栏 | 实时显示鼠标位置的X/Y坐标(mm) |

## 五、它认识哪些数据

1. **普通NC文件夹**：`1.nc、2.nc、3.nc…`（文件名开头数字=层号；同层多个文件自动合并）
2. **分组NC**：`12-0-0.nc、12-0-1.nc`（第一个数字=层号）
3. **merged索引**：文件夹里有`merged/index.json`的大任务格式（秒开）

只要文件里是带X/Y坐标的G00/G01行就能认，别的行自动忽略。
